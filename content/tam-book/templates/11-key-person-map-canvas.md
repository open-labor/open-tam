# 模板 11　关键人地图画布

> 用途：单一客户组织内关键人网络的盘点与维护工具（第 7 章 7.2 节配套）。三条链看清楚"谁拍板、谁影响拍板、谁会挡你"，两铁律管维护：反单点依赖（三层覆盖）、季度刷新＋关键岗位变动两周内更新（附录 G L2.10 核查点）。模板 10 健康分的 R1（关键人覆盖度）从本画布取数。
> 用法：每季度例行刷新一次；客户组织架构调整、关键岗位变动时两周内更新；画布中的"空白层"直接生成下季度行动清单。本文件含客户人员态度评价，属敏感信息——存内部系统，不进对外材料，访问权限按附录 B.3.6/B.3.7 数据边界执行。
> 时点：v0.1，2026-10 随书拟稿。

> **接班人列不可空**——客户人员变动是关系网络最大的单点故障；实在看不清就写"未知"，并在第 4 节行动清单立项去摸清。

## 2. 覆盖度核查（铁律一：反单点依赖）

| 层级 | 有无"可通话的人" | 名单 | 缺口动作 |
| --- | --- | --- | --- |
| 执行层 | □ 有　□ 无 | | |
| 管理层 | □ 有　□ 无 | | |

- 三层任一为空 = 客户关系裸奔，缺口动作直接进下季度行动清单；
- 全客户只有一名接口人可通话 = 单点依赖，按高危处理（第 7 章 7.8 误区 2）。

## 3. 防线人物专项（铁律外的第三条链）

防线人物：竞争对手的支持者、被你的故障报告暴露过问题的人、对厂商天然戒备的合规岗。防线不是敌人，是需要专门策略的利益相关方。

| 防线人物 | 防线来源 | 当前策略（不绕/不压/不激化的具体化） | 争取信号观测（他开始在评审会上引用你的数据） |
| --- | --- | --- | --- |
| | | | |

纪律：正面接触、用交付物说话（RCA 写扎实、评审报告给证据）、在其上级面前保持专业中性（第 7 章 7.2）。

# 模板 05　重保 Checklist 与值守手册

> 对应《The TAM Book of AI Era》第 18 章（重大保障方法论）、附录 B 流程 P5。
> 用法：按重保级别 L1–L4 裁剪——**体检和预案两个环节不可裁剪，只能简化**；其余按级别缩减投入强度。本模板可直接复制执行，每个检查项须落实负责人与证据（文档/截图/记录链接）。

### 2.2 交接班清单（每班必过）

| □ | 交接项 | 说明 |
| --- | --- | --- |
| □ | 当前未闭环事件与处置进展 | 逐条过，含下一步动作与负责人 |
| □ | 窗口内已执行/待执行的变更 | 冻结期内此项应为空，非空即违规 |
| □ | 监控大盘异常指标与趋势苗头 | 含"看着不太对但没说清"的直觉项 |
| □ | 资源到位状态（专家 oncall、备件、扩容余量） | 变动必须明示 |
| □ | 下一班次的通报时间与对象 | 交班人确认接班人已知 |

### 2.3 通报模板

**固定节奏简报**（每小时/每 2 小时，无论有无异常）：

```
【重保简报】HH:00 | 窗口 T±N
- 总体状态：正常 / 关注 / 异常
- 核心指标：交易成功率 __%｜响应时间 __ms（基线 __ms）｜容量水位 __%
- 事件：无 / 有（见异常通报）
- 下一次通报：HH+1:00
```

**异常通报**（初判后 10 分钟内发出，不等结论）：

```
【异常通报】HH:MM | 级别 P_（初判）
- 现象：________（影响面先说）
- 当前动作：________
- 下一步与升级安排：________
- 下一次通报：HH:MM（没结论也按时通报）
```

### 2.4 升级路径（贴墙用，值守前电话逐一验证）

| 触发条件 | 升级到 | 时限 |
| --- | --- | --- |
| P3 事件 | 技术组长 | 即时 |
| P2 事件 / P3 处置 30 分钟无进展 | 总指挥 + 双方接口人 | 即时 |
| P1 事件 | 双方管理层 + 厂商专家 oncall | 15 分钟内 |
| 涉及监管报送可能延误 | 客户合规/管理层（按沟通方案口径） | 按监管时限倒推 |

## 第三部分　重保结果报告骨架（T+7 内产出）

1. 成功标准核验表（逐条：目标值 / 实际值 / 结论）；
2. 窗口内流量与系统指标曲线（交易成功率、响应时间、容量水位三张图起步）；
3. 事件与苗头清单（含未触发阈值的"差点出事"项，逐条分析与处置回顾）；
4. 预案命中率与演练问题回写情况；
5. 改进项清单（责任人 / 关闭期限 / 纳入例会跟踪）；
6. 对客户管理层的价值总结（三段：挡住了什么 / 验证了什么 / 发现了什么）。

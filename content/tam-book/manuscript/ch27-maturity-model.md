# 第 27 章　TAM 成熟度模型

> 第 26 章解决了"怎么量"，本章解决"量完怎么读"。成熟度模型是全书的通用标尺：附录 G 的评估等级（S–D）、附录 N 的驻场认证（C1–C3）、附录 O 的晋升通道、附录 J 的培训分级（T1–T3）、模板 12 的自检得分率，全部锚定在本章的个人五级（M1–M5）上。本章定义标尺本身，别处只映射、不另立。

## 27.1 为什么需要成熟度模型

没有成熟度模型的团队，谈论人的成长只用两个词："行"和"不行"。这导致三个系统性问题：晋升靠年头和感觉，能者多劳到 burnout，培训一刀切。成熟度模型的价值不是给人贴标签，而是提供一套**共同语言**——让"他还差什么"可以被具体讨论，让客户分配、排班授权、培训投入有据可依。

三条定位原则：

1. **成熟度是能力标尺，不是职称体系**：它描述"你能可靠承担多大的场面"，不与薪酬等级直接挂钩（那是 HR 体系的事，第 28 章谈接口）；
2. **成熟度按证据判定，不按年头**：五年重复一年经验的人仍是 M2；判定依据是可核验的行为与结果证据（附录 O 的晋升证据标准同源）；
3. **成熟度是动态的**：可以升也可以降——长期脱离一线、证据链断裂的 M4 应回到 M3 重新积累，降档不是惩罚，是对客户负责。

## 27.2 个人五级：M1–M5

| 级别 | 名称 | 一句话定义 | 可独立承担 |
| --- | --- | --- | --- |
| M1 | 执行者 | 按指令和模板完成标准动作，判断需上级兜底 | 长尾客户辅岗；不可独立值班 M2 以上班次 |
| M2 | 可靠接口人 | 流程执行可靠、升级及时，客户日常界面站得住 | 独立承担一般客户；独立值 M2 班（附录 I） |
| M3 | 顾问 | 主动预防、能设计服务方案，六维无明显短板 | 独立承担重点客户；架构评审与重保骨干 |
| M4 | 战略伙伴 | 高层对话、跨厂商仲裁、风险预判，客户把你当自己人 | 金融级/旗舰级客户；Go/No-Go 唱票权 |
| M5 | 行业影响力 | 方法论输出者与标准制定者，能力可复制给他人 | 带团队、定标准、对外发声（本书附录系列即 M5 产出形态） |

**各级的可观察锚点与常见误判**：

- **M1 → M2 的跃迁标志**：从"做完"到"闭环"——行动项不用人催、交接不用人问、异常知道升级。误判：把"态度好、响应快"当 M2，流程闭环证据为零的不算；
- **M2 → M3 的跃迁标志**：从"接住问题"到"问题变少"——风险登记册里有他主动录入的项，健康检查产出被客户采纳过。误判：把"工龄够、客户熟"当 M3，只会救火不会预防的仍是 M2；
- **M3 → M4 的跃迁标志**：从"技术可信"到"政治可信"——客户高层决策前会私下问他的意见；跨团队冲突中各方接受他的仲裁。误判：把"技术最强"当 M4，M4 的核心增量在判断力与信任资产（第 4 章核心公式）；
- **M4 → M5 的跃迁标志**：从"自己会"到"让别人会"——有沉淀的方法论、有可复制的打法、有带出来的 M3。误判：把"名气大、PPT 好"当 M5，没有可核验的他人成长证据不算。

**六维与级别的关系**：六维能力（第 5–10 章）+ AI 杠杆是评价的内容维度，M1–M5 是综合高度。M3 要求六维无短板（单项最低 3 分，附录 G 的 B 级线），M4 以上允许有短板但必须有明确长板且短板不触红线。

## 27.4 团队五级

个人有标尺，团队也有。团队成熟度不看个体之和，看**体系是否大于个体**：

| 级别 | 名称 | 判定特征 |
| --- | --- | --- |
| 一级 | 应急队 | 服务质量系于个别骨干，骨干休假质量塌方 |
| 二级 | 标准化 | 有流程有模板，新人能按图索骥；执行质量仍看人 |
| 三级 | 体系化 | 流程闭环有度量（第 26 章口径落地），质量不依赖个人在场 |
| 四级 | 数据驱动 | 健康分、质量记分卡驱动资源分配与预防动作；指标防异化机制在运转 |
| 五级 | 行业输出 | 方法论对外输出（标准、白皮书、行业分享），团队成为招聘磁石 |

跃迁纪律与个人同理：按证据不按年头；最常见的自欺是把"买了平台"当三级——平台闲置率 80% 的团队仍是二级。

## 27.5 使用纪律

1. **评定与校准**：个人级别由直属主管初评、跨主管校准会定级（与附录 G 年度评估合并进行，一次证据两处使用）；自评（模板 12）是输入不是结论；
2. **客户分配挂钩**：M3 以下不独立承担 AA 级/金融核心客户，授权例外须服务总监书面批准并限期（与附录 N 授权边界一致）；
3. **降级机制**：连续两年证据不足、或触发附录 G 否决条款的，降级重评；降级记录不公开示众，但对排班与客户分配即时生效；
4. **禁止拔苗**：为填客户坑把 M2 推上 M4 场面，是对员工和客户的双重不负责——场面缺口靠组织资源补（增援、驻场组、服务模式调整），不靠个人越级硬扛。

## 27.6 常见误区

1. **把成熟度当年功**：到年限就提名，证据链空空——附录 O 已明确破格只破年限不破证据；
2. **用 M5 标准要求所有人**：团队健康结构是正态分布，全员 M4 的幻觉以 burnout 收场；
3. **级别终身制**：评上 M4 就永久占据旗舰客户，能力退化无人问津——降级机制是模型可信的前提；
4. **团队级别贴金**：汇报材料写"四级团队"，翻开指标全是手工填报——先过第 26 章的取数纪律再谈级别。

---

**本章要点回顾**

1. 成熟度模型是共同语言：让"还差什么"可讨论，让客户分配、授权、培训有据；按证据不按年头，可升也可降。
2. 个人五级 M1–M5（执行者/可靠接口人/顾问/战略伙伴/行业影响力），跃迁标志分别是：做完→闭环、接住→变少、技术可信→政治可信、自己会→让别人会。
3. 27.3 映射表是全书唯一映射事实源：附录 G（S–D）、N（C1–C3）、O、J（T1–T3）、模板 12 得分率统一锚定 M1–M5；标尺、成绩、授权、自查四者同源不同用。
4. 团队五级看体系是否大于个体：应急队 → 标准化 → 体系化 → 数据驱动 → 行业输出；买平台不等于体系化。
5. 使用纪律四条：校准会定级、客户分配挂钩、降级机制、禁止拔苗。
